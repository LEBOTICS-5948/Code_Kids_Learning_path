## Lesson 0: App Installations ⚙️

In this introductory lesson, you'll install all the essential software tools you need to start programming a FRC robot following the Lebotics and FRC standards.

**Pasos a seguir:**

1.  **Install [Visual Studio Code (Base IDE)](<https://code.visualstudio.com/>):**
    * **¿What it is?** The simple, long-standing IDE used mostly by programmers due to all the integrations it has and allows.
    * **Todo:** Simply install the IDE called Visual Studio Code and learn how to use it in a basic way.

2.  **Install [Visual Studio Code WPILIB (IDE)](<https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html>):**
    * **¿What it is?** This is the primary Integrated Development Environment (IDE) we'll use to write, edit, and manage our Java code for the robot. This one is better because it's provided directly by FRC and allows you to run the robot's code and simulate it, which will be covered later in the course.
    * **Todo:** Download and install the latest version from the link. Remember, you'll need to decide which version to download depending on your operating system.

3.  **Install [Elastic (Dashboard)](<https://github.com/Gold872/elastic-dashboard/releases/tag/v2025.2.2>):**
    * **¿What it is?** It is a "dashboard" or control panel that allows us to view robot data in real time (sensor values, status, etc.) and send simple commands.
    * **Todo:** Download and install Elastic. You may need to check for the recommended version or the latest version compatible with FRC tools.

4.  **Instalar [FRC Game Tools](<https://www.ni.com/es/support/downloads/drivers/download.frc-game-tools.html#553883>):**
    * **¿What it is?** This is a critical software package distributed by NI (National Instruments) and FIRST. It includes:
        * **Driver Station:** The app you'll use on your laptop to enable/disable the robot, view its status, and control it with joysticks during testing and competition.
* RoboRIO imaging tools, radio configuration, etc.
    * **Todo:** Download and install the full FRC Game Tools package. Installation is usually guided by the WPILib documentation.

5.  **Install [Path Planner](<https://apps.microsoft.com/detail/9nqbkb5dw909?hl=en-US&gl=US>):**
    * **¿What it is?** A specific tool used to design and generate complex trajectories for autonomous robot movements.
    * **Todo:** Download and install or configure the tool according to the specific instructions for Path Planner.

6.  **Install [Rev Hardware Client](<https://docs.revrobotics.com/rev-hardware-client/gs/install>):**
    * **¿What it is?** It's an essential tool used for REV Robotics electronic components (such as SPARK MAX motor controllers, Power Distribution Hub, etc.). It allows you to connect these devices to your computer via USB-C for configuration, updates, and diagnostics.
    * **Todo:** Download and install the Rev Hardware Client from the REV Robotics website.

---

Once you've completed these steps, you'll have the basic development environment ready to start working with the robot code in the following lessons.
