## Lección 0: Instalaciones De Apps ⚙️

En esta lección inicial, instalarás todas las herramientas de software esenciales que necesitas para empezar a programar un robot de FRC siguiendo el estándar de Lebotics y de FRC.

**Pasos a seguir:**

1.  **Instalar [Visual Studio Code (IDE Base)](<https://code.visualstudio.com/>):**
    * **¿Qué es?** El IDE sencillo de toda la vida utilizado mayormente por programadores debido a todas las integraciones que tiene y permite tener.
    * **Acción:** Instalar simplemente el IDE llamado Visual Studio Code y aprender a usarlo de manera basica.

2.  **Instalar la [Visual Studio Code WPILIB (IDE)](<https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html>):**
    * **¿Qué es?** Es el Entorno de Desarrollo Integrado (IDE) principal que usaremos para escribir, editar y gestionar nuestro código Java para el robot. Este es mejor debido a que lo provee FRC directamente y permite ejecutar el codigo del robot y simular, cosas que se veran mas adelante en el curso.
    * **Acción:** Descarga e instala la última versión desde el link. Recuerda, dependiendo tu sistema operativo tendras que ver el cual descargar.

3.  **Instalar [Elastic (Dashboard)](<https://github.com/Gold872/elastic-dashboard/releases/tag/v2025.2.2>):**
    * **¿Qué es?** Es un "dashboard" o panel de control que nos permite visualizar datos del robot en tiempo real (valores de sensores, estados, etc.) y enviar comandos simples.
    * **Acción:** Descarga e instala Elastic. Puede que necesites buscar la versión recomendada o la más reciente compatible con las herramientas de FRC.

4.  **Instalar [FRC Game Tools](<https://www.ni.com/es/support/downloads/drivers/download.frc-game-tools.html#553883>):**
    * **¿Qué es?** Este es un paquete de software crucial distribuido por NI (National Instruments) y FIRST. Incluye:
        * **Driver Station:** La aplicación que usarás en tu laptop para habilitar/deshabilitar el robot, ver su estado, y controlarlo con joysticks durante las pruebas y la competencia.
        * Herramientas de imagen del roboRIO, configuración de radio, etc.
    * **Acción:** Descarga e instala el paquete completo de FRC Game Tools. Usualmente, la instalación se guía desde la documentación de WPILib.

5.  **Instalar [Path Planner](<https://apps.microsoft.com/detail/9nqbkb5dw909?hl=en-US&gl=US>):**
    * **¿Qué es?** Una herramienta específica utilizada para diseñar y generar trayectorias complejas para los movimientos autónomos del robot.
    * **Acción:** Descarga e instala o configura la herramienta según las instrucciones específicas para Path Planner.

6.  **Instalar [Rev Hardware Client](<https://docs.revrobotics.com/rev-hardware-client/gs/install>):**
    * **¿Qué es?** Es una herramienta esencial, se utiliza para componentes electrónicos de REV Robotics (como controladores de motor SPARK MAX, Power Distribution Hub, etc.). Permite conectar estos dispositivos a tu computadora vía USB-C para configurarlos, actualizarlos y diagnosticarlos.
    * **Acción:** Descarga e instala el Rev Hardware Client desde el sitio web de REV Robotics.

---

Una vez completados estos pasos, tendrás el entorno de desarrollo básico listo para empezar a trabajar con el código del robot en las siguientes lecciones.
