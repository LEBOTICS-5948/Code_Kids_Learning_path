# Coding Knowledge Transfer

### Objective :dart:
This repository contains a compilation of exercises and resources designed to help students familiarize with FRC coding, specifically the architecture and best practices used by **Lebotics #5948**

### Prerequisites :rocket:

- **Basic knowledge of Java**
  - Variables
  - Decision Structures
  - Cycles
  - Functions
- **Windows 10 or higher***
    - In case you want to control de robot from your computer
 
## [Lesson 0: Getting Set Up](https://github.com/LEBOTICS-5948/Code_Kids_Learning_path/tree/main/Lesson_0) :gear:
In this lesson you will install all the tools needed to start coding for an FRC robot.
- Visual Studio Code (IDE)
- WPILib Extension (FRC specific funcionality to code robots)
- Elastic (Dashboard)
- FRC Game Tools (Driver Station)
- Path Finder (To create Autonomous routines)
- Rev Hardware Client (Helps manage REV devices)

## Lesson 1: Dashboard :world_map:	
In this lesson you will learn how to create your own Dashboard using **Elastic**.

## Lesson 2: Intake (Basics) :joystick:		
In this lesson you will learn:
- Types of motors used in FRC
- How to assign ID's (and review them in **Rev Hardware Client**)
- How to add limits

## Lesson 3: Intake (Advanced) :video_game:	
In this lesson you will learn how to:
- Configure motors
- Move an intake forward and backward
- How to control a mechanism remotely

## Lesson 4: Debugging :no_entry:	
In this lesson you will be presented with case scenarios to test your problem-solving skills.
By the end of the session, most common solutions will be shared.

## Lesson 5: Encoders :mag:	
In this lesson you will learn how to read and modify encoders.

## Lesson 6: Autonomous 101 :chess_pawn:	
In this lesson you will learn how to create your own autonomous routins using **Path Finder**.

## Lesson 7: Github :floppy_disk:	
In this lesson you will create your own Github account and learn the most basic commands needed for it.

## Lesson 8: Swerves :racing_car:	
In this lesson you will learn the basics of swerves and the techniques our team have mastered for them over the years.

## Challenge #1 :white_check_mark:	
This is the time for you to put into practice everything you have learned so far!
